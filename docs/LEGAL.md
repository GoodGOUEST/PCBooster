# 法务与权利保护清单

> **本文不是法律意见**，只是把个人开发者能落地的动作列清楚；关键决定请咨询律师。

## 为什么"只选 GPL"不够

GPL 是**附条件的著作权许可**：对方不合规 → 授权终止 → 其复制/分发构成**著作权侵权**，可以主张停止侵害与赔偿。它有判例支撑（美国 *Jacobsen v. Katzer* 2008、德国 Welte 系列禁令、中国 2015 年数字天堂诉柚子案），**不是"君子协定"**。

但它是**自助式**的：没有执法机关替你维权、不分发就不触发义务、跨境诉讼成本高。所以现实中最有效的组合是：

```
GPL-3.0-or-later + CLA  →  法律抓手 + 保留双许可
软著登记              →  证明"这是我的"（最实用）
商标注册              →  防套壳（最有效）
商业授权入口          →  把"想闭源用"变成生意
发布留痕              →  证明时间线
```

## 1. 软件著作权登记（优先做）

**为什么**：GPL 维权第一步永远是"证明这软件是我的、什么时候创作的"。登记证书是国内最省事的所有权证据。

| 项 | 说明 |
|---|---|
| 受理机构 | 中国版权保护中心（线上提交，也可找代理） |
| 官费 | **已免收**（登记费取消），代理费自选（几百元） |
| 周期 | 一般 30–60 个工作日（可加急） |
| 需提交 | 申请表；**源代码前后各 30 页**（每页 ≥50 行；总量不足 60 页则全交）；软件说明书（功能、运行环境、界面截图）；身份证明 |
| 名称建议 | 与产品一致，例如「PC Booster 系统资源调度软件 V3.6」 |
| 与开源冲突吗 | **不冲突**。已公开的源码同样可以登记；GPL 不影响著作权归属 |

**源码前后各 30 页怎么取**：建议取"入口 + 核心调度"两段（例如 `Program.cs` 开头 + `SchedulerCoordinator` 关键实现），确保能体现独创性。

## 2. 商标注册（防套壳最有效）

GPL 允许别人 fork 改代码，但**不允许用你的名字和图标**。这才是对"改个壳就发布"最直接的约束。

| 项 | 说明 |
|---|---|
| 类别 | **第 9 类**（计算机软件/可下载程序）；预算允许可加 **第 42 类**（软件设计与开发） |
| 官费 | 网上申请约 ¥270/类（含 10 个商品项） |
| 代理费 | ¥500–1500/类（建议用代理，驳回率更低） |
| 周期 | 约 9–12 个月；提交后可用 `™`，注册成功后用 `®` |
| 建议 | 中英文名称一并申请（“PC Booster” + 中文名），并注册图标 |

配套动作：README 已加入**名称与图标条款**（衍生发行版必须改名换图标），这条在投诉时很有用。

## 3. 发布留痕（零成本）

- Git 提交时间线本身就是"创作时间"的证据（保留上游分支历史，别 squash 掉全部历史）
- Release 说明里附 **SHA256**，并保留构建用的 commit id
- 发布包内嵌版本信息（本项目已嵌入 `FileVersion`）
- 重要节点可用**可信时间戳**（第三方时间戳服务，几元/次）或公证

## 4. 维权路径（由轻到重）

1. **平台投诉**：GitHub DMCA / 网盘 / 应用商店 / 国内软件站的侵权投诉通道（成本最低，往往最快）；
2. **律师函**：指出 GPL 义务 + 商标侵权，要求整改或购买商业授权；
3. **诉讼**：主张著作权侵权（停止侵害 + 赔偿），必要时加商标侵权；
4. **组织协助**：GPL 类问题可联系 Software Freedom Conservancy 等组织（对个人项目帮助有限，但可作为谈判筹码）。

> 现实提醒：跨境/匿名侵权执行成本极高。**把精力放在"商标 + 渠道投诉 + 口碑"上，比准备打官司划算。**

## 5. 常见误区

| 误区 | 事实 |
|---|---|
| “GPL 能禁止别人做同类工具” | ❌ 不能。它只约束**你的代码**的复制与分发 |
| “GPL 能禁止公司内部使用” | ❌ 不能。没有分发就没有 GPL 义务 |
| “开源了就不能卖钱” | ❌ 可以。你可以同时卖商业授权、卖服务、卖定制 |
| “GPL 会传染给调用它的软件吗” | ⚠️ 取决于是否构成衍生作品。**通过进程调用/独立程序交互一般不算**；链接/静态合并通常算。本项目是独立可执行程序，用户运行它不产生义务 |
| “MIT 更自由所以更好” | 看目标：MIT 允许别人闭源改造后不反馈，这与本项目“反蛇油”的定位相冲突 |
